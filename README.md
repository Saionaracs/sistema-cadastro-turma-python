# 🎓 Sistema de Cadastro de Turma em Python

![Python](https://img.shields.io/badge/Python-3.x-blue?style=for-the-badge&logo=python)
![Status](https://img.shields.io/badge/Status-Concluído-success?style=for-the-badge)

Projeto desenvolvido para consolidação de conceitos fundamentais de lógica de programação, estruturas de dados e manipulação dinâmica de coleções em Python.

---

## 📌 Funcionalidades

- **Cadastro Dinâmico**: Utilização do laço `while` permitindo ao utilizador cadastrar quantos alunos desejar.
- **Tratamento de Dados**: Validação automática de entradas com substituição de vírgula por ponto (`.replace(',', '.')`) para conversão de números decimais (`float`).
- **Sanitização de Texto**: Uso dos métodos `.strip()` e `.upper()` para garantir que respostas de controle (`S/N`) sejam interpretadas corretamente.
- **Estruturação Robusta**: Armazenamento dos dados de cada aluno num **Dicionário** (`{}`) e agregação da turma numa **Lista** (`[]`).
- **Relatório Formatado**: Exibição final dos dados formatados com precisão de duas casas decimais (`:.2f`).

---

## 🛠️ Tecnologias e Conceitos Aplicados

- **Python 3**
- **Estruturas de Repetição**: `while` e `for`
- **Estruturas Condicionais**: `if` / `else`
- **Estruturas de Dados**: Listas e Dicionários (Lista de Dicionários)
- **Manipulação de Strings e Formatação (`f-strings`)**
